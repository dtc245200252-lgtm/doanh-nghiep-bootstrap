# Tạo Trang Giới Thiệu Doanh Nghiệp với Bootstrap

Trang web giới thiệu doanh nghiệp chuyên nghiệp sử dụng Bootstrap 5.

## Các thành phần
- **Navbar**: Thanh điều hướng thương hiệu `Doanh Nghiệp`, tông màu sáng `navbar-light bg-light`, menu căn phải `ms-auto`.
- **Hero Section**: Mở đầu thu hút với tiêu đề lớn, khẩu hiệu và nút Call to Action (`btn btn-light`).
- **About Section**: Giới thiệu tổng quan về sứ mệnh và dịch vụ của công ty.
- **Services Section**: Hệ thống lưới 3 cột hiển thị các dịch vụ chính (Thiết kế Website, Marketing Online, Hỗ trợ khách hàng).
- **Contact Section**: Thông tin liên hệ gồm Email và Hotline.
- **Footer**: Bản quyền chân trang với nền tối `bg-dark text-white`.

## Cài đặt
Sử dụng Bootstrap 5 CDN. Mở file `index.html` trực tiếp trên trình duyệt để kiểm tra.
